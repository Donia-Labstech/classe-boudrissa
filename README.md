# DONIA SMART CLASSE
### توزيع الأقسام الذكي للمؤسسات التعليمية الجزائرية

تطبيق ويب يبني تلقائيًا أفواج السنة الدراسية القادمة لمتوسطتك وفق القواعد الرسمية لوزارة التربية الوطنية الجزائرية — مع تعديل يدوي كامل وبوابة إلكترونية للتلاميذ وتصدير Excel.

تطوير **[DONIA LABS TECH](https://donialabstech.online)** — حلول رقمية مبتكرة لأجلكم

</div>

---

## ✨ المزايا الرئيسية

- توزيع تلقائي بخوارزمية ذكية 3 مراحل: الأوائل + الموازنة + تدوير المعيدين
- خريطة مدرسية تفاعلية لكل مستوى مع تحديث فوري
- بوابة إلكترونية للتلاميذ: يُدخل التلميذ اسمه ويرى فوجه ويطبع استمارته
- استيراد مباشر لملفات منظومة وزارة التربية (xls/xlsx)
- تصدير Excel بترويسة رسمية لكل مستوى
- نسخ احتياطي كامل بصيغة JSON قابل للاسترجاع على أي جهاز
- وضع ليلي + قابل للتثبيت كتطبيق مستقل (PWA)
- كل البيانات محفوظة محليًا في المتصفح فقط — لا خادم، لا إنترنت مطلوب
